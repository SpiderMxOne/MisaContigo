Política de Privacidad

Última actualización: Junio 2024

Diego Torres Barragán ("nosotros") opera la aplicación móvil MisaContigo. Esta página le informa sobre nuestras políticas con respecto a la recopilación, el uso y la divulgación de datos personales cuando utiliza nuestra Aplicación.

1. Recopilación de Información

Micrófono: Nuestra aplicación solicita permiso de grabación de audio para permitir la funcionalidad de comandos de voz. El audio se procesa localmente en el dispositivo para convertirlo a texto y no se almacena en nuestros servidores.

Ubicación (GPS): Si usted lo permite, utilizamos su ubicación para ayudarle a encontrar parroquias cercanas. Esta información se utiliza en el momento y no se almacena de forma permanente.

Base de Datos Local: Las oraciones favoritas y los miembros de su círculo familiar se almacenan únicamente en su dispositivo.

2. Uso de Inteligencia Artificial

MisaContigo utiliza la API de Google Gemini para generar contenido litúrgico y espiritual. No enviamos datos que lo identifiquen personalmente a este servicio.

3. Seguridad de los Datos

La seguridad de sus datos es importante para nosotros. Recordamos que ningún método de transmisión por Internet o método de almacenamiento electrónico es 100% seguro, pero aplicamos las mejores prácticas de desarrollo para proteger su información.

4. Cambios en esta Política

Podemos actualizar nuestra Política de Privacidad periódicamente. Le notificaremos cualquier cambio publicando la nueva Política de Privacidad en esta página.

5. Contacto

Si tiene alguna pregunta sobre esta Política de Privacidad, puede contactarnos en: spidermxone@gmail.com
